# Simple Contact Management System in C

A console-based application for managing a personal contact list. This program allows users to add new contacts, display the entire list of contacts, and search for a specific contact by name.

**Note:** This version stores contacts in memory, so the list will be cleared each time the program is closed.

## Features

-   **Add Contact:** Add a new contact with a name, phone number, and email.
-   **Display All Contacts:** View a formatted list of all saved contacts.
-   **Search Contact:** Find a contact by their name.
-   **Interactive Menu:** A simple and easy-to-use menu for navigation.

## How to Compile and Run

1.  **Compile the C code:**
    ```bash
    gcc contacts.c -o contacts
    ```

2.  **Run the executable:**
    ```bash
    ./contacts
    ```
